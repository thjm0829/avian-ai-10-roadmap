# 10. 추진 일정

> **작성 상태:** 세부 내용 작성 완료
>
> **핵심 결론:** 본 사업은 2026년 사업·규제·현장 정의와 비감염 Mock 시제품 개발을 시작으로, 2027년 단일 Sampling Point 통합과 첫 농장 운영검증, 2028년 전문기관 비교검증과 소수농장 실증, 2029년 유료 시범사업과 공공조달 준비, 2030년 충북 10개 농가 지역사업, 2030~2031년 타 지자체 확산 순서로 추진한다. 각 단계는 단순한 날짜가 아니라 사전에 정한 기술·규제·현장·사업화 통과조건을 충족했을 때 다음 단계로 넘어가는 Gate 방식으로 운영한다.

본 시스템은 조류인플루엔자를 확진하는 장비가 아니다. 추진 일정의 목적은 빠른 전국 보급을 먼저 선언하는 것이 아니라, 분변 기반 AIV 신속항원 반복검사의 자동화가 기술적으로 재현 가능하고 전문기관의 기준검사와 비교할 수 있으며 농장과 공공 방역체계 안에서 지속적으로 운영될 수 있는지를 단계적으로 확인하는 데 있다.

현재 일정의 기준시점은 **2026년 8월**이다. 조류인플루엔자 특별방역대책기간과 정부 지원사업 일정은 매년 달라질 수 있으므로, 연도·분기별 기본 구조는 유지하되 정부 공고, 전문기관 협의와 현장실증 준비상태에 따라 세부 월은 조정한다.

## 공모전 단계와 공모전 이후 실행 구분

공모전 문서는 기술·사업 가설과 실행순서를 제시하는 기준계획이다. 공모전 선정 이후에는 다음 자료를 확보하면서 각 Gate의 일정과 예산을 재기준화한다.

| 확보자료 | 반영 Gate | 일정에 미치는 영향 |
|---|---|---|
| 키트 IFU·검역본부 사전협의 | Gate 0 | 사용목적·시험범위·허가경로 확정 |
| 농장 구조조사·사용자 인터뷰 | Gate 0~2 | Sampling 위치와 초기 대상농장 확정 |
| 부품·OEM·키트 복수견적 | Gate 1~2 | BOM·제작수량·예산 재산정 |
| 예비 반복시험 | Gate 1~3 | KPI 목표·시험표본·설계 동결 |
| 전문기관 시험계획·비용 | Gate 4 | 실제 검증기간과 자금계획 확정 |
| 지자체 예산·조달검토 | Gate 5~7 | 유료실증·10농가 사업시점 확정 |

일정은 날짜보다 통과조건을 우선한다. 견적, 규제회신 또는 전문기관 일정이 늦어지면 다음 Gate를 자동으로 늦추며, 공모전 일정에 맞추기 위해 감염성 검체시험이나 공공실증을 앞당기지 않는다.

| 2029년 4분기~2030년 | Gate 7. 충북 지역사업 | 지자체 1곳·농가 10곳의 B2G2B 운영모델 검증 | 10대 운영실적, 공공관제, 성과평가, 재계약 자료 | 반복운영계약 및 타 지역 확산근거 확보 |

위 농장 수와 시점은 현재 사업계획용 목표다. 실제 농장 수는 전문기관 시험설계, 참여기관의 예산, 제품 허가·신고경로와 현장협약에 따라 조정한다.

## 10.1 단기: 시제품

단기 단계는 2026년 3분기부터 2027년 3분기까지로 설정한다. 이 기간에는 실제 감염농장 성능을 주장하지 않고, 비감염 Mock 환경에서 **1 Sampling Point / 1 Analysis Unit**의 End-to-End 동작을 구현한 뒤 정상농장에 설치할 수 있는 수준의 시제품을 확보한다.

### 10.1.1 단기 개발 원칙

1. 초기 직접신호는 분변 기반 AIV 신속항원검사로 유지한다.
2. 공기포집이나 환경센서만으로 AIV 감염을 판단하는 기능은 개발범위에 포함하지 않는다.
3. 현재 적용대상은 계분벨트식 산란계·종계 농장이다.
4. 깔짚식 육계·오리농장은 현재 Sampling 구조를 그대로 적용하지 않고 별도의 후속시장으로 둔다.
5. 검체접촉부는 일회용 Wet Zone, 모터·카메라·제어기·통신부는 다회용 Dry Zone으로 구성한다.
6. 상용 AIV 신속항원키트의 면역반응 자체를 변경하지 않고 전처리·분주·시간관리·촬영·기록을 자동화한다.
7. T/C 값은 정성판독을 보조하는 반정량 optical signal로 저장하고 바이러스량이나 RNA copy 수로 환산하지 않는다.
8. 초기 AI는 규칙기반 Risk Engine과 통계적 이상탐지 구조로 시작한다.
9. 한 Sampling Point가 축사 전체를 완전히 대표한다고 주장하지 않는다.
10. 실제 감염성 검체는 팀이 임의로 취급하지 않는다.

### 10.1.2 Gate 0 — 사업·규제·현장 정의  
**기간: 2026년 3~4분기**

시제품을 제작하기 전에 장치의 사용목적과 규제·시험범위를 먼저 고정한다. “확진장비가 아니다”라는 표현만으로 동물용의료기기 또는 동물용체외진단의료기기 규제에서 제외된다고 가정하지 않는다.

주요 수행내용:

- 제품 사용목적과 사용자 정의
- 장치 본체, 자동분주부, Camera Reader와 Risk Software의 제품경계 정의
- 농림축산검역본부 대상 규제분류 사전상담 준비
- 동물용의료기기·동물용체외진단의료기기 해당 가능성 검토
- 상용 AIV 신속항원키트 후보의 사용설명서 확보
- 허용검체, 완충액, 분주량, 판독시간과 보관조건 확인
- Composite Sample과 자체 전처리가 키트 허가범위에 미치는 영향 검토
- OEM 생산 시 제조자·품목허가자·판매자 책임구조 검토
- 충북 동물위생시험소, 수의과대학, 연구기관 등 협력후보 접촉
- 계분벨트식 산란계·종계 농장의 설치환경 조사
- 스크레이퍼, 낙하구간, Cross Conveyor, 전원·통신과 세척환경 측정
- 농장 출입·소독·장치 설치·시료폐기 절차 초안 작성
- 2027년 농식품 창업·실증지원사업 신청자료 준비

핵심 산출물:

- 제품 사용목적 및 역할구분서
- 규제분류 질의서와 상담기록
- 키트 후보 비교표와 Kit Profile 초안
- 농장 설치환경 조사표
- Sampling Point 설치 인터페이스
- 전문기관 공동검증 개념계획서
- MVP 요구사항과 제외범위
- 개발·시험 Risk Register

Gate 0 통과조건:

- 본 시스템이 확진과 법정 방역조치를 수행하지 않는다는 역할이 문서화돼 있을 것
- 최소 1종 이상의 키트 후보와 사용조건을 확보할 것
- 초기 대상농장과 설치위치를 확인할 것
- 규제·시험경로의 핵심 질의사항을 전문기관과 협의할 수 있을 것
- Mock 개발과 실제 검체시험의 경계를 분리할 것

### 10.1.3 Gate 1 — Analysis Unit MVP  
**기간: 2026년 4분기~2027년 2분기**

이 단계에서는 사람이 비감염 모사시료를 일회용 카트리지에 넣은 이후부터 자동으로 처리하는 Analysis Unit을 먼저 완성한다.

~~~text
사람이 Mock Cartridge 장착
        ↓
카트리지 장착감지
        ↓
자동 혼합
        ↓
침전시간 관리
        ↓
상층액 위치제어·자동채취
        ↓
Cassette Sample Well 자동분주
        ↓
제품별 반응시간 관리
        ↓
고정 카메라·조명 촬영
        ↓
C선·T선 판독과 QC
        ↓
정성 결과 + T/C 반정량 신호
        ↓
검사이력 DB / 기본 Dashboard
~~~

하드웨어 개발:

- 일회용 전처리·침전 카트리지 단면설계
- 카트리지 장착·밀폐 감지
- 혼합·교반 메커니즘
- 침전시간 제어
- 상층액 자동채취용 Tip 또는 Dropper 구조
- Cassette Stage와 위치고정
- 시료 자동분주 메커니즘
- 고정 Camera Reader와 외부광 차단
- 누액·도어·리미트·용기 상태 센서
- Dry Zone과 Wet Zone 분리구조
- 기본 외함과 유지보수 접근구조

소프트웨어 개발:

- 하위제어 State Machine
- 검사 스케줄과 반응시간 관리
- Sample·Cartridge·Kit·Image ID 연결
- Camera 촬영과 이미지 저장
- Cassette ROI 탐지
- C-line·T-line 영역 추출
- 배경보정과 광학신호 계산
- Positive·Negative·Invalid·Uncertain 분류
- 초점·노출·위치·C선 유효성 QC
- T/C 반정량 신호 저장
- Rule-Based Risk Engine
- Reason Codes와 Recommended Action
- 자동 재촬영과 Mock 자동재검
- 엣지 저장과 서버 동기화
- 농장·공공·운영자 기본 Dashboard

시험항목:

- 카트리지 반복 장착
- 혼합시간과 동작 반복성
- 상층액 위치제어
- 침전물 과다흡입 여부
- 분주 위치와 동작 반복성
- Cassette 장착감지
- 반응시간 기록
- 동일 Cassette 반복촬영
- C선 미검출 Invalid 처리
- 흐림·과노출·위치이탈 QC
- 전원·통신장애 후 안전복귀와 데이터 보존
- 동일 Mock 입력에 대한 Risk Level·Reason Code 재현성

Gate 1 통과조건:

- 안전한 Mock 조건에서 전체 Analysis Cycle이 순차적으로 동작할 것
- 실패·중단·재시도·복구상태가 검사이력에 남을 것
- C선 미검출과 영상품질 문제를 양성·음성으로 강제판정하지 않을 것
- 원본 이미지, 정성결과, C선·T선 신호, T/C, QC와 알고리즘 버전이 연결될 것
- 검체접촉부와 다회용 본체가 기능적으로 분리될 것
- 장치부터 Dashboard까지 데이터 추적이 가능할 것

### 10.1.4 Gate 2 — 1 Sampling Point 통합  
**기간: 2027년 2~3분기**

Analysis Unit이 안정화되면 계분벨트의 단일 Sampling Point와 연결한다.

현재 기준 설치위치:

> **계분벨트 끝단 스크레이퍼 이후, 횡방향 계분 컨베이어에 떨어지기 이전의 낙하구간**

주요 수행내용:

- 계분벨트·스크레이퍼·Cross Conveyor 시험모형 제작
- Sampling Arm 실제 치수와 암 길이 확정
- Sampling Cup 형상과 일회용 Insert 설계
- 평상시 낙하경로 밖 대기와 안전복귀
- Belt Run Signal·Encoder·Hall Sensor 또는 비침습 운전감지 비교
- 벨트 운전 중 여러 시점의 순간 진입
- 반복 소량채취와 Composite Cartridge 통합
- Sampling Event·Cycle·Point ID 기록
- Cartridge 자동전달 또는 작업자 인계구조
- Sampling Unit과 Analysis Unit 통합 State Machine
- 막힘·누액·과부하·센서오류와 긴급정지
- Preliminary CAD, 내부 Layout과 핵심 BOM 확정

시험항목:

- 예정된 Sampling Event 대비 실제 채취·복귀
- 정상 계분배출 간섭 여부
- Sampling Event 누락과 중복
- Composite Sample 생성
- 벨트속도·분변상태·Sampling Timing 변화
- Cartridge 장착과 인계
- Sampling Point부터 Test Result까지 추적성
- 오류 후 안전대기상태 전환
- 유지보수 접근성과 일회용 부품 교체

Gate 2 통과조건:

- Sampling Arm이 정상 배출을 방해하지 않는 대기위치로 복귀할 것
- 여러 Sampling Event를 하나의 Composite Cartridge에 모을 수 있을 것
- Sampling Point·Cycle·Event가 검사데이터와 연결될 것
- 단일 Sampling Point에서 채취부터 판독·저장까지 End-to-End 시연할 것
- 실제 농장 설치 전 위험요소와 안전대책이 문서화될 것

### 10.1.5 단기 최종 산출물

- 1 Sampling Point / 1 Analysis Unit 통합 시제품
- Sampling Unit·Analysis Unit Preliminary CAD
- 일회용 Wet Zone 시제품과 교체절차
- Camera C선·T선 판독 프로토타입
- Mock 검사 데이터 생성기
- Rule-Based Risk Engine과 자동재검
- 농장·공공·운영자 Dashboard
- 장치 State Machine과 오류복구표
- 핵심 BOM과 시제품 원가
- 설치·운영·세척·폐기 SOP 초안
- 전문기관 공동검증 시험계획 초안
- MVP Acceptance Criteria 결과서

단기단계에서 확정하지 않는 값:

- 실제 농장별 최적 검사주기
- Sampling Event 횟수와 간격
- Composite Sample 최적량과 희석비
- 한 Sampling Point의 대표범위
- 키트별 T/C 위험 임계값
- 민감도·특이도
- 조기경보 선행시간
- 살처분 감소율과 예산 절감률

## 10.2 중기: 전문기관 검증·농장 실증

중기 단계는 2027년 4분기부터 2029년 1분기까지로 설정한다. 한 번의 짧은 실증으로 기술·진단·현장·사업효과를 동시에 주장하지 않고, 첫 동절기 정상운영, 전문기관 비교검증, 두 번째 동절기 소수농장 실증으로 구분한다.

### 10.2.1 Gate 3 — 첫 번째 동절기 농장 운영검증  
**기간: 2027년 4분기~2028년 1분기**

첫 번째 동절기에는 감염탐지 정확도보다 정상농장 장기운영과 baseline 확보를 우선한다.

초기 설치대상:

- 계분벨트식 산란계·종계 농장
- 장치 설치공간과 전원·통신 확보가 가능한 농장
- 벨트 운전신호 또는 운전주기 확인이 가능한 농장
- 장기운전·소모품 교체·점검에 협조할 수 있는 농장
- 경보·재검·전문기관 연락절차를 수행할 수 있는 농장
- 비식별 실증데이터 활용에 동의할 수 있는 농장

주요 검증내용:

- 계분벨트 운전주기와 Trigger 안정성
- Sampling Unit 물리적 간섭과 안전복귀
- 분변 수분·점도·협잡물 변화
- 온도·습도·분진·암모니아 영향
- 농장별·Sampling Point별 정상 baseline
- Invalid·Uncertain·오경보 발생양상
- 장치 가동률과 자동검사 완료율
- 관리자 개입시간
- 소모품 교체와 폐기시간
- 통신두절 시 로컬저장과 재동기화
- 원격진단과 장애복구
- 농장 출입·세척·소독 절차
- 공공관제화면의 기본 활용성

B2G2B 대응 모의훈련:

~~~text
Mock 위험신호 발생
        ↓
장치 QC와 동일 조건 자동재검
        ↓
농장 관리자 확인
        ↓
지자체 관제담당자 알림
        ↓
전문기관 확인 필요성 검토
        ↓
공식 시료채취·검사 절차 모의연결
        ↓
조치결과와 시간기록
~~~

Gate 3 통과조건:

- 농장환경에서 장기간 반복운전이 가능할 것
- 주요 장애·무효검사 원인과 개선안이 확보될 것
- 농장별 baseline을 구축할 수 있는 데이터 완전성이 있을 것
- 농장·지자체·전문기관의 경보대응 절차가 문서화될 것
- 전문기관 비교시험에 투입할 장치·알고리즘 버전을 고정할 것

### 10.2.2 Gate 4 — 전문기관 공동검증  
**기간: 2028년 2~3분기**

실제 분변, 상용 AIV 신속항원키트와 기준검사의 비교는 수의·바이오 전문가 및 적절한 전문기관의 승인된 절차 안에서 수행한다.

검증 순서:

1. 동일 Cassette 반복촬영과 Camera Reader 재현성
2. 수동분주와 자동분주의 결과 비교
3. 분변 전처리와 상층액 회수 반복성
4. 수동 키트판독과 장치판독 비교
5. Composite Sample 구성에 따른 희석·대표성 영향
6. 키트 결과와 RT-qPCR 등 기준검사의 paired comparison
7. 단일 검사와 반복 시계열 기반 재검 우선순위 비교
8. 자동재검이 일시 오류와 반복 위험신호를 구분하는지 평가

주요 평가항목:

- 실제 분변의 수분·점도·고형물 영향
- 전처리 회수율과 상층액 재현성
- 침전물 혼입과 검사 방해요인
- 시료 간 교차오염과 carry-over
- 키트 제조사·모델·Lot별 변동
- C선 탐지와 Invalid 분류
- 정성판독 일치도
- 동일 Cassette 반복촬영 T/C 변동
- 자동검사와 수동검사의 동등성
- 기준검사와의 일치도
- 위양성·위음성
- T/C와 기준검사 값의 관계
- 경보시점과 공식검사 시점
- 공식검사 Label과 메타데이터 완전성

검증 원칙:

- AI 간이키트 결과는 공식 확진으로 사용하지 않는다.
- 신속항원검사 음성만으로 감염 가능성을 배제하지 않는다.
- 실제 감염성 AIV 검체는 프로젝트 팀이 임의로 취급하지 않는다.
- Mock 결과를 진단성능으로 표현하지 않는다.
- T/C를 바이러스 절대농도나 Ct 값으로 직접 환산하지 않는다.
- 실패·Invalid·Uncertain 결과도 제외하지 않고 원인별로 기록한다.
- 성능지표는 공식검사 Label이 확보된 이후 계산한다.
- 농장과 시간단위의 데이터 누수를 방지한다.

Gate 4 통과조건:

- 전문기관 검증보고서와 원자료 추적성이 확보될 것
- 장치가 사용할 수 있는 키트·검체·전처리 조건이 정해질 것
- 성능을 주장할 수 있는 범위와 주장할 수 없는 범위가 구분될 것
- 규제 신청 또는 추가시험에 필요한 자료목록이 확정될 것
- 판매용 제품설계와 알고리즘 버전이 동결될 것
- 농장 장기실증의 중단·신고·공식검사 연결조건이 합의될 것

### 10.2.3 Gate 5 — 두 번째 동절기 소수농장 실증  
**기간: 2028년 4분기~2029년 1분기**

전문기관 비교검증 이후에는 충북 내 2~5개 수준의 협력농장을 대상으로 장기 반복운영을 수행한다. 농장 수는 사업계획용 가정이며 전문기관 시험설계와 예산에 따라 조정한다.

주요 수행내용:

- 농장별 장치 설치·시운전
- 정부가 공고한 특별방역기간을 포함한 **Risk-based Adaptive Testing** 원칙의 위험도 기반 검사운영
- NORMAL·WATCH·CAUTION·ALERT 단계별 검사강도와 대응절차 비교
- 농가당 연 60회·100회·150회 시나리오의 기술·운영·경제성 검토
- 실제 검사빈도는 전문기관 실증과 방역기관 협의를 거쳐 확정
- 무효·재검률, 유효기간과 분할조달을 반영한 시나리오별 안전재고 관리
- 농장별 baseline과 T/C 변화추세
- 자동재검과 관리자 확인
- 경보 후 지자체·전문기관 연락절차
- 공식검사 결과와 장치경보의 사후비교
- 장치 가동률·검사 유효성·장애복구
- 관리자 개입시간과 농가 수용성
- 유효검사 1회당 소모품·운영비
- 실제 사용량 기반 중앙 소모품 재고와 유효기간 관리
- 공공관제 담당자의 확인 우선순위 활용
- 데이터 접근권한·감사로그·보존정책 검증

실증 산출물:

- 농장별 설치환경과 표준 설치절차
- Sampling·전처리·분주·판독 검증자료
- 장기운영 가동률과 유효검사 자료
- 오경보·미탐·Invalid·장애 사례분석
- 경보 선행시간과 공식검사 연결시간 후보
- 농장·지자체·전문기관 사용자평가
- 경보대응 표준운영절차
- 유지보수·소모품 공급계획
- 유효검사 1회당 비용
- 데이터 보안·권한·보존정책
- 공공 수요기관 사용평가서 초안

Gate 5 통과조건:

- 전문기관이 검토한 실증결과가 확보될 것
- 농장 장기운영과 유지보수가 가능한 수준일 것
- 경보·재검·공식검사 연결절차가 실제 운영 가능할 것
- 유료 시범사업에서 제시할 제품범위·가격·서비스수준이 정해질 것
- 규제·품질·제품책임 요건이 해결되거나 해결계획이 계약에 반영될 것

### 10.2.4 유료실증 전환 원칙

무상실증은 제한된 기능검증 범위에서만 수행한다. 농장 장기운영부터는 다음 항목 중 하나 이상을 유료화하여 실제 공공수요와 사업지속성을 확인한다.

- 장치 제작·설치
- 검사소모품
- 공공관제 플랫폼
- 원격운영·정기점검
- 현장 장애대응
- 실증·성과평가 보고

유료실증으로 전환하기 전에는 다음을 갖춘다.

- 제품 규격서
- 시험·검증보고서
- 설치·운영·경보대응 SOP
- 생산·품질관리 계획
- 소모품 공급과 폐기계획
- 데이터 보안·책임범위
- A/S와 하자보수 기준
- 원가와 판매가격 산출근거
- 실증 종료 후 구매·철거·데이터 처리조건

## 10.3 장기: 충북→전국 확대

장기 단계는 2029년부터 2031년까지로 설정한다. 첫 유료실증과 충북 10개 농가 지역사업을 통해 공공조달과 반복운영의 기준을 만들고, 이후 인접 지자체로 확산한다.

### 10.3.1 Gate 6 — 유료실증과 공공조달 준비  
**기간: 2029년**

주요 수행내용:

- 농가 1곳 또는 소규모 유료 시범계약
- 제품·서비스 공급범위와 SLA 확정
- 제조·OEM·검사·출하 품질체계 구축
- 장치 Serial, Cartridge Lot, Kit Lot 추적체계
- 정기점검·교정·예비부품·현장출동 기준
- 제품책임·보험·하자보수 검토
- 조달 입찰참가자격과 물품목록번호 준비
- 벤처나라 지정·등록 검토
- 혁신제품 신청자료와 수요기관 협력 준비
- 충북 10개 농가 사업 제안서 작성
- 전문기관 검증자료와 수요기관 사용평가서 확보
- 검사량 시나리오와 실제 사용량을 반영한 10개 농가 소모품 분할조달계획
- 첫해부터 장치 구축계약, 연간 고정 운영계약과 검사량 연동 변동비를 구분

벤처나라는 초기 공공판로와 소규모 구매에 활용하되, 농가당 연 100회 기준 첫해 총 계약예산 125,000,000원의 10개 농가 사업 전체가 벤처나라 간편구매만으로 자동 체결된다고 가정하지 않는다. 지역 단위 사업은 지자체 실증·용역·물품구매, 혁신제품 시범구매 등 실제 계약경로를 수요기관과 협의한다. 이 금액은 가격구조 비교용 기준 시나리오이며 실제 검사빈도와 계약예산은 실증과 방역기관 협의를 반영해 조정한다.

Gate 6 통과조건:

- 실제 유료계약 또는 유료실증 실적이 있을 것
- 제품 생산과 품질검사 주체가 확정될 것
- 규격서·가격·A/S·소모품 공급체계가 준비될 것
- 수요기관이 10개 농가 사업의 예산·계약경로를 검토할 수 있을 것
- 판매 전 필요한 허가·신고·인증 조건을 충족할 것

### 10.3.2 Gate 7 — 충북 1개 지자체·10개 농가 지역사업  
**기간: 2029년 4분기~2030년**

초기 지역사업은 **지자체 1곳·농가 10곳**을 기본단위로 한다.

첫해 사업구조:

**A. 장치 구축계약**

- 자동검사 장치 10대 제작·설치: 70,000,000원
- 농가별 설치·시운전과 담당자 교육
- 경보대응 매뉴얼과 전문기관 연결절차
- 사업성과 평가보고

**B. 연간 고정 운영계약**

- 공공 AI 관제 플랫폼: 15,000,000원/년
- 유지관리: 15,000,000원/년
- 고정 반복 계약예산: 30,000,000원/년

**C. 실제 검사량 연동 변동비**

- 독자 Cartridge·Wet Zone 공급: 10,000원/검사
- 제3자 AIV 키트: 15,000원/검사
- 검사 1회 총 계약예산: 25,000원/검사
- 제3자 키트는 지자체 직접조달 또는 실비성 통과항목으로 처리하며 핵심 마진원으로 보지 않는다.

연간 계약예산은 다음 산식으로 관리한다.

> **연간 계약예산 = 30,000,000원 + 실제 검사횟수 × 25,000원**

| 농가당 연간 검사횟수 | 10개 농가 총검사 | 2년 차 이후 연간 계약예산 | 첫해 총 계약예산 |
|---:|---:|---:|---:|
| 60회 | 600회 | 45,000,000원 | 115,000,000원 |
| **100회** | **1,000회** | **55,000,000원** | **125,000,000원** |
| 150회 | 1,500회 | 67,500,000원 | 137,500,000원 |

농가당 연 100회는 손익과 가격구조를 비교하기 위한 사업계획 기준 시나리오이며 정부 공식 검사주기나 최종 운영주기가 아니다. 실제 검사빈도는 전문기관 실증과 방역기관 협의를 통해 확정한다.

100회 기준 시나리오의 첫해 직접 사업원가는 74,960,000원, 매출총이익은 50,040,000원, 매출총이익률은 40.0%다. 2년 차 이후 연간 총 계약예산은 55,000,000원이며, 이 중 제3자 AIV 키트 실비분을 제외한 핵심매출은 40,000,000원이다. 연간 직접 사업원가는 32,000,000원, 매출총이익은 23,000,000원, 매출총이익률은 41.8%다. 같은 검사량을 5년간 단순 적용하면 총 계약예산은 345,000,000원, 직접 사업원가는 202,960,000원, 매출총이익은 142,040,000원, 매출총이익률은 41.2%다.

모든 금액은 부가가치세 별도 잠정 추정치이며 장비 양산견적, 키트 국내 조달가격, Composite Cartridge OEM 견적과 규제·실증 결과에 따라 갱신한다.

운영기준:

| 위험수준 | 검사운영 개념 | 경보·대응 원칙 |
|---|---|---|

| ALERT | 즉시 재검 | 관리자 확인 후 공식검사 연결 |

소모품은 연간 고정수량을 일괄 확보하지 않고 60회·100회·150회 시나리오, 실제 사용량, 무효·재검률, 유효기간과 조달기간을 반영해 분할조달한다. 재고와 예산의 기준값은 실증결과와 방역기관 협의 후 갱신한다.

### 10.3.3 Gate 8 — 충북 확산과 타 지역 확대  
**기간: 2030~2031년**

권장 확장목표:

- 지자체 1곳·농가 10곳: 유료실증과 첫 조달실적
- 지자체 3곳·농가 30곳: 초기 운영조직 유지기반
- 지자체 5곳 이상·농가 50곳 이상: 반복매출과 플랫폼 규모의 경제
- 이후 충청권·중부권·전국 공공조달 검토

지역확산 순서:

~~~text
충북 소수 계분벨트식 농장
        ↓
충북 1개 지자체·10개 농가
        ↓
충북 고위험 산란계 농장군
        ↓
충청권·중부권 3~5개 지자체
        ↓
계열화사업자 참여형 공공사업
        ↓
타 시·도 지역 단위 관제
        ↓
전국 공공조달·공식 방역체계 연계 검토
~~~

확장 전 준비사항:

- 지역밀집형 유지보수 거점
- 중앙 소모품 조달과 재고관리
- 농장·지자체·전문기관 교육체계
- 장치 원격진단과 예방정비
- 표준 설치환경과 예외처리
- 지역별 데이터 권한과 책임
- 제품·알고리즘·Kit Lot 변경관리
- 정기 성과보고와 재계약 기준
- 규제·품질·보안 감사대응

전국 확산은 설치대수만으로 결정하지 않는다. 공식검사 연결시간, 장치 가동률, 유효검사율, 유지관리비, 공공담당자 활용률과 재계약률을 종합하여 결정한다.

### 10.3.4 Multi-point Monitoring 고도화

단일 Sampling Point의 대표성 한계를 보완하기 위해 기본 제품이 안정화된 이후 동일 축사 내 2~3개 독립 Sampling Node를 비교한다.

~~~text
Sampling Point A → 독립검사 → Result A
Sampling Point B → 독립검사 → Result B
Sampling Point C → 독립검사 → Result C
                             ↓
                    Software Risk Integration
~~~

개발원칙:

- 각 지점의 검체를 먼저 혼합하지 않는다.
- 지점별 원본 이미지, T/C, QC와 재검결과를 유지한다.
- 특정 지점의 이상신호가 평균에 의해 희석되지 않게 한다.
- 장치·키트·유지관리 비용 증가를 함께 평가한다.
- 단일지점 대비 검출 가능성이나 공간적 대표성의 개선폭을 실증 전 확정하지 않는다.

Multi-point 진입조건:

- 단일 Node의 기계·검사·운영 안정성 확보
- 단일지점 대표성 한계에 대한 현장자료 확보
- 추가 노드의 비용과 유지관리 타당성 확인
- 지점별 독립검사를 수행할 예산과 전문기관 시험설계 확보

### 10.3.5 Epidemiological Risk Graph 고도화

세 번째 핵심기술은 이동데이터 접근권한을 처음부터 전제하지 않는다.

단계적 추진:

1. Mock Farm·Vehicle·Facility·Visit 데이터로 Graph 구조 개발
2. 참여농장·계열화사업자가 정당하게 보유한 데이터로 검증
3. 지자체·공공기관과 이용목적·법적근거·최소수집 범위 협의
4. 허가된 이동관계 데이터 연계
5. Biological Risk와 Movement Risk 결합
6. 관련농장과 확인·추적 우선순위 제안
7. 전문기관 공식 역학조사 결과와 사후비교

이 기능은 KAHIS 등 기존 국가시스템을 대체하지 않고, 감염경로나 공식 역학관계를 자동 확정하지 않는다. 공식 확인이 필요한 농장과 이동관계의 우선순위를 제시하는 의사결정 지원기능으로 제한한다.

### 10.3.6 타 축종·타 감염병 확장

육계·오리농장과 다른 가축전염병은 기존 제품을 그대로 복제해 적용하지 않는다.

확장조건:

- 축종별 사육시설과 분변관리방식 조사
- 새로운 Sampling Point와 Sampling Node 설계
- 질병별 검체·표지자·검사키트 선정
- 전처리와 분석성능 별도검증
- 전문기관 기준검사 비교
- 새로운 규제·허가범위 확인
- 별도 원가와 시장성 평가

확장은 다음 순서를 기본으로 한다.

| 단계 | 확장방향 | 선행조건 |

| 1 | 계분벨트식 산란계·종계 | 현재 MVP와 전문기관 검증 |
| 2 | 충북 내 다농장·다계사 | 지역운영과 유지보수 안정화 |
| 3 | 타 지역 계분벨트식 농장 | 공식검사 비교와 조달실적 |
| 4 | 육계·오리용 별도 Node | 새로운 Sampling 방식 검증 |
| 5 | 관련시설·이동거점 | 시설별 포집·방역절차 검증 |
| 6 | 타 가축전염병 | 질병별 분석성능과 규제 재검토 |

## 일정 변경 및 중단 기준

다음 상황에서는 날짜를 유지하기 위해 무리하게 다음 단계로 진행하지 않고 일정과 제품역할을 조정한다.

### 기술적 중단·수정조건

- 반복 Sampling이 계분배출을 방해하거나 안전복귀가 불안정한 경우
- Composite Sample의 변동이 커 비교 가능한 검사데이터를 만들기 어려운 경우
- 전처리 방해물질과 고형물 문제를 제어하지 못하는 경우
- 자동분주가 수동분주 대비 충분한 반복성을 확보하지 못하는 경우
- Camera Reader의 T/C 변동이 시계열 비교에 부적합한 경우
- 교차오염과 폐기물 관리위험을 통제하기 어려운 경우

### 진단·실증 중단·수정조건

- 신속항원키트의 허용검체와 장치 전처리 방식이 부합하지 않는 경우
- 실제 분변에서 신호가 지나치게 불안정한 경우
- 자동재검과 시계열 분석이 우선순위 판단에 추가정보를 제공하지 못하는 경우
- 공식검사보다 의미 있는 선행정보를 확보하지 못하는 경우
- 오경보와 Invalid가 현장운영을 방해하는 수준인 경우

이 경우 시스템 역할을 다음과 같이 조정할 수 있다.

- 자동 시료관리와 검사기록 장치
- 신속키트 자동판독과 품질관리 장치
- 재검 우선순위와 장치상태 관리 플랫폼
- 전문기관용 연구·실증 데이터 수집장치

### 사업·제도 중단·수정조건

- 필요한 규제·허가경로가 사업비와 기간에 맞지 않는 경우
- 전문기관·농장·지자체 협력구조가 확보되지 않는 경우
- 소모품비와 유지관리비가 공공고객의 지불의사를 초과하는 경우
- 유료실증과 후속구매로 전환되지 않는 경우
- 데이터 이용권한과 책임범위를 합의하지 못하는 경우

일정의 성공기준은 개발항목을 계획된 날짜에 모두 완료하는 것만이 아니다.

- 장치가 반복 가능한 검사데이터를 생성하는가
- 전문기관이 결과를 기준검사와 비교할 수 있는가
- 농장이 실제 방역절차 안에서 장치를 운영할 수 있는가
- 지자체가 경보와 조치이력을 공공관제에 활용할 수 있는가
- 개발기업이 소모품·유지보수·플랫폼을 지속 공급할 수 있는가
- 실증이 유료사업과 반복계약으로 전환되는가

위 조건이 확인될 때 단계적으로 다음 지역과 기술로 확대한다. 검증되지 않은 정확도, 조기탐지 시간, 피해예방액과 비용절감률은 목표값이나 확정성과로 사용하지 않는다.
